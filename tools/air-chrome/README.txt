ETC Air for Chrome
==================
Lets the ETC Air Apple Watch app control ANY web page in this Chrome, not just the ETC Lab portal.

Install (once)
1. In Chrome, open  chrome://extensions
2. Switch on "Developer mode" (top right).
3. Click "Load unpacked" and choose this folder (ETCAir-Chrome).
4. Pin it: click the puzzle icon in the toolbar, then the pin next to "ETC Air".

Use
- You must be signed in to the ETC Lab admin in this Chrome (the extension uses that sign-in; no password is stored here).
- The badge says ON when it is linked. Click the icon to switch it OFF or ON.
- Open the ETC Air app on the watch, raise your arm, and the ring appears on whatever page is in front.

Gestures are the same as on the portal. On other sites, "swing left/right" moves one screenful down/up
(or sends the arrow keys on slide-style pages).

It does not work on Chrome's own pages (chrome://, the Web Store) or in the built-in PDF viewer.
